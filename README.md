**Enzyme Function**

GALC encodes galactosylceramidase, an enzyme found in lysosomes. It breaks down certain lipids, including galactosylceramide and psychosine, which are important in the normal maintenance of myelin in the nervous system. Deficiency of this enzyme is associated with Krabbe disease.
